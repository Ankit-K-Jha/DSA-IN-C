## 🧠 Learning Approach

For each algorithm or data structure, I aim to understand:

* **Concept**
* **Algorithm**
* **Pseudocode**
* **C Implementation**
* **Time Complexity**
* **Space Complexity**
* **Best, Average & Worst Cases** where applicable

The goal is not just to write the code, but to understand **why and how the algorithm works**.

## 📊 Complexity Analysis

| Topic     | Technique      | Time Complexity    |
| --------- | -------------- | ------------------ |
| Array     | Insertion      | O(n)               |
| Array     | Deletion       | O(n)               |
| Array     | Find Maximum   | O(n)               |
| Searching | Linear Search  | O(n)               |
| Searching | Binary Search  | O(log n)           |
| Sorting   | Bubble Sort    | O(n²)              |
| Sorting   | Selection Sort | O(n²)              |
| Sorting   | Insertion Sort | O(n²)              |
| Sorting   | Merge Sort     | O(n log n)         |
| Sorting   | Quick Sort     | O(n log n) average |
| Sorting   | Heap Sort      | O(n log n)         |
